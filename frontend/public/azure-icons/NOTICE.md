# Microsoft Azure architecture icons

`Management-Groups.svg`, `Subscriptions.svg`, `Resource-Groups.svg` and `Policy.svg` are unmodified copies of icons from
Microsoft's **Azure Public Service Icons V24** (<https://learn.microsoft.com/azure/architecture/icons/>), the same files
as `scripts/subscription_analysis/azure_icons/` (see the NOTICE there). They are Microsoft's, not part of ARG's
MIT-licensed code. The Policy page's assignment tree shows each one only for the scope or service it was designed for,
unaltered (only scaled), with its name next to it.
